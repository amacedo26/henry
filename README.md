# Presupuesto mensual

Versión web interactiva de la planilla de presupuesto mensual, pensada para el público en general.

## Cómo usarla

Abrí `index.html` en cualquier navegador (doble clic alcanza, no necesita servidor ni internet).

- **Previsto**: lo que planeás ganar o gastar en el mes.
- **Real**: lo que efectivamente pasó.
- Los totales, el saldo y las diferencias se calculan solos.
- El gráfico compara previsto vs. real por categoría.
- Podés agregar o quitar ítems en cada categoría.
- Los datos se guardan automáticamente en tu navegador (no se envían a ningún servidor). El botón **Restablecer** vuelve a la plantilla vacía.

Funciona en celular y computadora, con modo claro y oscuro automático.
